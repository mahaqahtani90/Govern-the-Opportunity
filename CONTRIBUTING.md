# Contributing to Govern the Opportunity

Thank you for helping improve an open, practical approach to AI opportunity governance and task-level qualification.

## Ways to contribute

- Report unclear definitions or scoring conflicts
- Propose evidence-backed scoring improvements
- Add a documented sector example
- Translate the framework
- Share anonymized pilot results
- Build an interoperable digital tool or schema

## Contribution workflow

1. Open an issue describing the problem, evidence, and proposed outcome.
2. Discuss material changes before submitting a pull request.
3. Submit a focused pull request with tests or worked examples where relevant.
4. A maintainer reviews methodological consistency, safety, and backward compatibility.
5. Accepted changes appear in the changelog and the next version.

## Evidence standard

Proposals affecting thresholds, scoring, risk routing, or decision authority should include at least one of:

- Documented pilot evidence
- Peer-reviewed or authoritative research
- Recognized standard or public-sector guidance
- Reproducible worked cases reviewed by domain experts

## Safety

Do not submit personal, confidential, restricted, production, or proprietary data. Examples must be synthetic or irreversibly anonymized.
