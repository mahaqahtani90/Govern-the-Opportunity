# Govern the Opportunity — Layer 1 of AI Governance

**Layer 1 of AI Governance**

> Govern the opportunity before governing the solution.

**Govern the Opportunity** is an open governance principle and framework for qualifying AI opportunities before solution design, procurement, or development begins.

The framework is operationalized through the **AI TaskFit 5D Method** and applies across AI types, including predictive systems, classification, recommendation, optimization, computer vision, generative systems, and autonomous agents.

It helps organizations answer four questions:

1. Is this task suitable for AI, and which AI capability fits it?
2. Is the expected value material and measurable?
3. What is the initial risk level?
4. What authority and human oversight should the system receive?

AI TaskFit is **Governance Gate 1**, not a complete AI governance system and not a substitute for legal, privacy, cybersecurity, architecture, model validation, or AI impact assessment.

## Framework architecture

| Layer | Name | Purpose |
|---|---|---|
| Principle | Govern the Opportunity | Govern the selection decision itself |
| Framework | AI Opportunity Governance | Define the first governance layer and routing |
| Method | AI TaskFit 5D | Assess a task through five repeatable stages |

## AI TaskFit 5D Method

| Stage | Purpose | Output |
|---|---|---|
| Decompose | Define one assessable task | Task definition |
| Determine | Score AI fit, value, and readiness | Opportunity score |
| Detect | Screen impact and risk | Initial risk level |
| Decide | Set the permitted usage mode | Governance route |
| Demonstrate | Validate value and controls through a pilot | Adoption decision |

## Governance position

`Business request → AI TaskFit → Detailed impact and risk assessment → Design and controls → Validation → Release and monitoring`

AI TaskFit primarily operationalizes **MAP** and early **MEASURE** activities from the NIST AI RMF and supports documented use-case evaluation and human oversight under ISO/IEC 42001. High-impact cases should proceed to a detailed assessment such as an AI system impact assessment aligned with ISO/IEC 42005.

## Public draft

This repository is **v0.1 Public Draft**. The scoring thresholds and routing rules are hypotheses to be validated through documented pilots and expert review. They must not be treated as regulatory approval or certification.
